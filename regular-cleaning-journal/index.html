현장 도착·작업 시작과 종료, 전후사진, 작업일지 제출과 관리자 확인을 시험할 수 있어요.

테스트 앱 실행

현재 앱은 개발 PC에서 실행 중이에요. 개발 PC 또는 디버깅으로 연결된 테스트 휴대폰에서 아래 버튼을 눌러 주세요.

정기청소 테스트 앱 열기

이 버튼은 지금 사용하는 기기의 127.0.0.1:8791로 이동해요. 다른 PC나 연결되지 않은 휴대폰에서는 열리지 않아요. 누구나 접속하는 인터넷용 앱 서버는 아직 배포하지 않았어요.

연결되지 않을 때
  1. 개발 PC에서 앱 서버가 켜져 있는지 확인해 주세요.
  2. 테스트 휴대폰은 개발 PC와 디버깅 연결 및 이 앱의 포트 연결이 유지되어야 해요.
  3. 다른 기기라면 아래 소스와 실행 안내를 확인해 주세요.

PC 실행 명령: 앱 폴더에서 python server.py --host 127.0.0.1 --port 8791

테스트 전 확인

합성 데이터 전용이에요. 실제 고객 정보나 현장 사진을 넣지 마세요. 기존 클린매니저·클린멤버 운영 시스템과 연결되지 않아요.
