# 현장노트 — 정기청소 독립 테스트 앱

**합성 데이터 전용 로컬 개발본. 기존 클린매니저·클린멤버에 연결하지 않습니다.**

2026-10-19 최종 검증: 실제 HTTP 접속, Edge·모바일 화면, Samsung Android12 Chrome의 네이티브 앨범·카메라·제출·관리자 확인, 사진 전송 복구·저속 통신·회전·서버 재시작 보존 통과. 상세는 [실제 검증 보고](docs/LIVE-VERIFICATION.md). 현재 PC에서는 서버를 켜 둔 상태로 인계한다. 연결된 휴대폰도 adb reverse가 유지되면 같은 주소로 접속한다. 외부 배포 주소는 아니다.

## 실행

Python 3.11 이상, 추가 패키지 설치 없음. 이 폴더에서:

```powershell
& .\Start-Lab.ps1
# 또는
python server.py --host 127.0.0.1 --port 8791
```

이 PC에서 `http://127.0.0.1:8791/`을 엽니다. 터미널에서 Ctrl+C로 종료합니다. 재실행하면 같은 `data/lab.sqlite3`와 `data/photos/`가 유지됩니다. 포트 충돌이면 `Start-Lab.ps1 -Port 8792`로 독립 포트를 지정합니다. 외부 인터넷 테스트 주소는 발급하지 않았습니다.

| 테스트 역할 | 아이디 | 비밀번호 |
|---|---|---|
| 작업자 | worker | Worker-test-2026! |
| 관리자 | admin | Admin-test-2026! |
| 다른 작업자(권한 시험) | worker2 | Worker2-test-2026! |
| 다른 회사(격리 시험) | other | Other-test-2026! |
| 비활성(로그인 거절 시험) | inactive | Inactive-test-2026! |

공개된 위 계정은 **테스트 전용**입니다. 운영 인증·비밀번호 재설정·계정 발급 체계로 사용하지 않습니다. 실명·연락처·실제 현장 정보·실제 사진을 넣지 마세요.

## 구현 기능

- 작업자: 본인 배정·약속 날짜 필터·과거 기록, 현장 도착→시작→종료, 체크리스트 완료/미실시 사유, 메모, 전후사진, 별도 제출과 관리자 확인 상태.
- 관리자: 소속 회사 현장·작업자 배정, 미작성/미시작/작업중/제출대기/검토대기/확인완료/보완요청 필터, 일지·사진 조회, 확인·보완, 실제 시각 정정, 내부 일정 조정·고객 약속 변경 및 확인 이력.
- 서버 검증: 세션·비활성 계정·회사/본인 배정·역할, CSRF·Origin, 서버 시각, 단일 배정 일지·중복 요청, 미종료 현장 중복 시작 차단, 낙관적 버전 충돌, 제출 조건, 수정 전후 원본 이력.
- 사진: JPG/PNG/WebP, 장당 5MB·일지당 12장, 계정·배정별 IndexedDB 대기열, 동일 uploadId 재전송 중복 방지, 서버 접수 후 대기열 제거, 비공개 원본 조회.
- 약속 날짜·오전/오후는 실제 작업 날짜와 분리. UTC 저장·한국시간 표시. 자정·오전 9시에 약속 배정이 바뀌지 않습니다. 표시 시간은 휴게를 제외하지 않은 경과시간이며 급여·정산이 아닙니다.
- 작업자 삭제·완료 취소 기능은 제공하지 않습니다. 사진은 원본 바이트를 저장하고 정정은 이력으로 보존합니다.

## 검증 실행

```powershell
python -m unittest discover -s tests -v
node tests/test_frontend.cjs
```

검증 범위·실행 결과와 제한은 [검증 보고](docs/VERIFICATION.md)에 정리합니다. Store·HTTP 처리기·DOM 모의환경 통과를 실제 HTTP 접속·모바일 브라우저·실제 휴대폰 통과로 해석하지 않습니다. `tests/browser-smoke.cjs`와 `tests/aside-ui-harness.js`는 브라우저 검증을 위한 준비 코드이며 미실행/실패 여부를 보고서로 구분합니다.

## 데이터와 백업

`data/`는 실행 시 이 앱 폴더 안에만 생성됩니다. `python backup.py`는 `backups/<시각>/`에 일관된 SQLite 사본과 사진 원본 사본을 새로 만듭니다. 기존 파일 삭제나 덮어쓰기는 하지 않습니다. 서버 정지 상태의 전체 `data/` 폴더 복사도 가능합니다. 복구는 서버 정지 후 백업을 새 폴더에 복사하고 `--data <복원폴더>`로 실행하여 먼저 검증합니다. 운영 시스템 백업·복원과 무관합니다.

## 운영 전 별도 작업

이 테스트 서버를 인터넷이나 실제 운영에 직접 공개하지 않습니다. 운영 배포·인증 공급자/계정 발급·HTTPS·보안 쿠키·비밀번호 재설정·보관기간·악성/손상 이미지 완전 디코딩 검사·사진 크기/회전 기기별 검증·회사별 확장·비용·연동·실제 데이터 이전은 별도 범위입니다. 현재 서버는 이미지 형식을 바이트 헤더로 제한하지만 완전한 이미지 디코더 검증까지 수행하지 않습니다. 시작/종료의 완전 오프라인 모드는 지원하지 않습니다.

아빠의 지정에 따라 기존 `dntprbs-maker/my-tools` 저장소의 `regular-cleaning-journal/` 폴더에 소스를 보관합니다. 실행 데이터·사진 원본·기기 화면 기록은 Git에서 제외합니다. 저장소의 정적 자동배포는 Python 서버를 실행하지 않으므로 앱 실행에는 위 로컬 명령이 필요합니다. 신규 Git 저장소·클라우드 프로젝트·계정·유료 자원은 생성하지 않았고, 기존 클린매니저·클린멤버 운영 코드·DB·인증·배포 설정도 변경하지 않았습니다.
