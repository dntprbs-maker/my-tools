# 아빠의 도구 모음

아빠가 업무와 개인적으로 사용하는 작은 프로그램, 계산기, HTML 도구를 한곳에서 보관하고 계속 관리하는 저장소입니다.

각 프로그램은 별도 폴더에 두고 실행 파일과 설명 문서를 함께 관리합니다. 프로그램이 커져 독립적인 서비스가 되면 별도 저장소로 분리할 수 있습니다.

## 프로그램 목록

| 프로그램 | 폴더 | 용도 | 상태 |
|---|---|---|---|
| AI 주간 사용량 계산기 | [`ai-usage-calculator/`](./ai-usage-calculator/) | AI별 주간 사용 계획과 잔여량 확인 | 설명 작성 완료 · 실행 파일 등록 대기 |
| 리버뷰 접수 등록 | [`river-view/`](./river-view/) | 리버뷰 유지보수 접수 내용 등록 | 1차 화면 구현 완료 · 아빠 확인 대기 |

## 관리 원칙

- 수정 전에 GitHub의 현재 버전을 먼저 확인합니다.
- 기존 원본을 업데이트하고 Git으로 변경 이력을 남깁니다.
- 기존 기능을 보존하며 요청한 부분을 우선 수정합니다.
- 프로그램 변경 시 해당 폴더의 README도 함께 최신화합니다.
