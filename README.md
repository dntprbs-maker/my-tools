# 여러가지 도구 모음

아빠가 업무와 개인 용도로 사용하는 작은 프로그램, 계산기, HTML 도구를 한곳에서 관리하는 저장소입니다.

## 관리 구조

각 도구는 별도의 폴더에서 관리합니다.

- 실행에 필요한 원본 파일
- 도구별 `README.md`
- 수정 이력

도구가 커지거나 독립 서비스가 되면 별도 저장소로 분리할 수 있습니다.

## 프로그램 목록

| 프로그램 | 폴더 | 상태 |
|---|---|---|
| AI 주간 사용량 계산기 | [`ai-usage-calculator/`](./ai-usage-calculator/) | 구조 준비 |

## 기본 원칙

- 기존 기능은 임의로 삭제하거나 변경하지 않습니다.
- 변경 전 현재 원본을 확인하고 Git 이력으로 변경 내용을 관리합니다.
- 프로그램 수정 시 해당 폴더의 README도 함께 최신화합니다.
- 스마트폰용 도구는 모바일 가독성을 우선합니다.
