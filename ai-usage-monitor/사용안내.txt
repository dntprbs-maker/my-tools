AI Usage Monitor — 사용 안내
==============================

이 PC에 로그인된 Claude Code / Codex 계정의 사용량(5시간·주간 한도)을 보여 주는 프로그램입니다.
설치할 필요 없이 폴더째 복사해서 쓰면 됩니다.

■ 처음 한 번
1. 이 ZIP을 풀어서 "AI Usage Monitor" 폴더를 원하는 곳에 둡니다.
   (권장: 바탕화면이나 문서 폴더. "C:\Program Files" 안에 두어도 되지만 그 경우 기록은 사용자 폴더에 저장됩니다.)
2. 폴더 안의 "AI Usage Monitor.exe"를 더블클릭합니다.
   - Windows가 "PC 보호" 파란 창을 띄우면 [추가 정보] → [실행]을 누릅니다. (서명되지 않은 개인 프로그램이라 뜨는 안내입니다)
3. 편하게 쓰려면 exe를 오른쪽 클릭 → [바탕화면에 바로 가기 만들기](Windows 11은 [더 많은 옵션 표시] 안에 있음).

■ 사용
- 창이 뜨면 [↻ 새로고침]을 누르면 현재 사용량을 가져옵니다. 자동으로는 조회하지 않습니다.
- 다음에 켜면 마지막으로 가져온 값이 먼저 보입니다.

■ 미리 필요한 것
- Claude 사용량: 이 PC에서 Claude Code(터미널의 claude 명령)에 로그인되어 있어야 합니다.
  (Claude 데스크톱 앱이나 웹 로그인만으로는 읽을 수 없습니다.)
- Codex 사용량: 이 PC에서 Codex에 "ChatGPT 계정"으로 로그인되어 있어야 합니다. (API 키 로그인은 해당 없음)
- 로그인이 없으면 화면에 "로그인 필요"라고 표시됩니다. 로그인한 뒤 새로고침하면 됩니다.
- Microsoft Edge WebView2 런타임(Windows 10/11 대부분 기본 설치). 없으면 실행 시 안내 창이 뜹니다.

■ 알아 둘 점
- 인증 정보는 이 PC 사용자 폴더의 기존 로그인 파일을 읽기만 합니다.
  단, Claude 로그인이 만료됐으면 그 로그인을 자동으로 새로 고쳐 같은 파일에 저장합니다(직전 파일은 .bak-monitor로 보관).
- Claude는 너무 자주 조회하면 30분 정도 "요청 제한"이 걸립니다. 그동안은 마지막 값이 유지됩니다.
- 조회 결과는 폴더 안 data\usage.json 에 최신 1개만 저장됩니다.
