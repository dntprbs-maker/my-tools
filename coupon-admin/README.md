# 쿠폰 관리자

`index.html`은 아빠 전용 공용 기프티쇼 관리자 `/owner`를 여는 진입점이다. 관리자 인증값이나 기프티쇼 상용 키는 이 정적 저장소에 넣지 않는다.

정식 배포된 「여러 가지 프로그램」에서 쿠폰 관리자 카드를 누르면 공용 서버의 `/owner` 로그인 화면으로 이동한다. 이 정적 페이지에는 아이디·비밀번호·세션 비밀값을 저장하지 않는다. 관리자 데이터는 서버에서 로그인 세션을 검증한 뒤에만 조회한다. 현재 연결 대상은 Railway 개발환경이며 모의발송 전용이다. 실제 쿠폰 구매·발송과 자동발송은 잠겨 있다.

클린멤버용 `쿠폰 관리` 메뉴는 클린멤버 기존 관리자 페이지에 유지한다.
