# 쿠폰 관리자

`index.html`은 아빠 전용 공용 기프티쇼 관리자 `/owner`를 여는 진입점이다. 관리자 인증값이나 기프티쇼 상용 키는 이 정적 저장소에 넣지 않는다.

도구 모음에서 클릭하면 Railway 개발 서버의 `https://coupon-api-development.up.railway.app/owner`로 이동한다. 이 페이지에는 관리자 인증값을 저장하지 않는다. 관리자 데이터는 공용 서버의 관리자 토큰 인증 뒤에만 조회된다. 현재 서버는 모의발송 전용이며 실제 쿠폰 구매·발송과 자동발송은 잠겨 있다.

클린멤버용 `쿠폰 관리` 메뉴는 클린멤버 기존 관리자 페이지에 유지한다.
