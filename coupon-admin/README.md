# 쿠폰 관리자

`index.html`은 아빠 전용 공용 기프티쇼 관리자 `/owner`를 여는 진입점이다. 관리자 인증값이나 기프티쇼 상용 키는 이 정적 저장소에 넣지 않는다.

현재는 첫 접속 때 개발 미리보기의 `/owner` 주소를 입력하고 브라우저에만 보관한다. 이후 도구 모음에서 클릭하면 바로 해당 화면으로 이동한다. 별도 클라우드 개발 서버가 준비되면 이 폴더의 연결 방식만 해당 서버의 HTTPS `/owner`로 교체한다. 실제 쿠폰 구매·발송과 자동발송은 공용 서버에서 잠겨 있다.

클린멤버용 `쿠폰 관리` 메뉴는 클린멤버 기존 관리자 페이지에 유지한다.
