# AI 주간 사용량 계산기

AI별 주간 사용 한도와 만료일시를 기준으로 계획 사용량, 잔여량, 남은 시간을 확인하는 계산기입니다.

## 용도

여러 AI의 주간 사용 현황을 한 화면에서 비교하고, 주간 한도를 날짜별 계획에 맞춰 사용할 수 있도록 돕습니다. 스마트폰에서 자주 확인하는 도구이므로 모바일 화면의 가독성과 조작 편의성을 우선합니다.

## 현재 기능

- AI별 이름 입력
- AI별 주간 사용 한도 만료일시 입력
- 만료일시 기준 자동 계산
- 주간 계획 사용량 계산
- 계획 사용량과 잔여량 동시 표시
- 만료까지 남은 시간 표시
- 진행 그래프
- 이전 주(`-1주`)와 다음 주(`+1주`) 이동
- 여러 AI 추가
- 입력값 브라우저 저장
- 스마트폰 한 화면에서 2개 AI 비교
- AI별 색상 구분

## 변경 원칙

- 변경하기 전에 GitHub의 현재 버전을 먼저 확인합니다.
- 기존 기능을 임의로 삭제하거나 바꾸지 않습니다.
- 요청받은 부분을 우선 수정하고 나머지 기능은 보존합니다.
- 큰 변경 전에는 복구할 수 있도록 Git 이력을 남깁니다.
- 프로그램 변경 시 이 README도 함께 최신화합니다.
- 모바일 화면의 가독성을 우선합니다.
- 다운로드용 HTML은 GitHub의 최신 원본을 기준으로 만듭니다.
