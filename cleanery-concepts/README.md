- `/cleanery-concepts/a/`: 기존 녹색·화이트와 대형 사진 구성을 유지한 부분 수정 방향.
- `/cleanery-concepts/b/`: 밝은 분할 화면과 청소 범위·과정 중심의 시각 디자인 개편 방향.

기존 `/cleanery/`, 원본 로컬 홈페이지, 데이터베이스, 상담봇, 클린매니저·클린멤버는 수정하지 않습니다.
접수·개인정보 입력·저장·전송은 없습니다. 견적 버튼은 견적 준비 안내창을 엽니다.
두 안은 선택을 위한 메인 페이지 시안이며 기존 8개 페이지의 전면 개편 완료를 의미하지 않습니다.

## 실행

저장소 루트에서 `python -m http.server 4324`를 실행한 뒤
`http://127.0.0.1:4324/cleanery-concepts/a/` 또는 `/b/`를 엽니다.
빌드·설치·환경변수·운영 키가 필요 없는 HTML/CSS/JS입니다.

## 이미지

`assets/IMAGE-PROVENANCE.md`에 도구·프롬프트·원본·배포 파일을 기록했습니다.
AI 생성 작업 예시이며 실제 크리너리 직원·현장·실적이 아닙니다.
WebP 800/1536px, 약 31/81KB, 첫 화면 이미지 우선 로딩을 적용했습니다.

## 검증

실제 Chrome, PC 1440×1000 / 모바일 390×844 / 소형 320×780에서 두 안을 확인합니다.
HTTP200, 단일 H1, 가로 넘침, 사진 로딩·표시, 개인정보 폼 부재, 모바일 메뉴,
범위 탭·키보드·ARIA 연결, FAQ, 안내창 열기·Escape 닫기, 앵커, 새로고침, 콘솔·리소스 오류를 검증합니다.
