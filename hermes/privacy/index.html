개인정보처리방침

앱 이름: Hermes Agent

운영 목적

이 앱은 프로젝트 소유자 본인의 개인 업무 자동화 및 Google Workspace 관련 개인 작업 수행을 위해 운영됩니다.

이용하는 Google 데이터

  • Gmail
  • Google Drive
  • Google Calendar
  • Google Docs
  • Google Sheets
  • Google Contacts

데이터 사용 목적

위 Google 데이터는 사용자가 직접 요청한 다음과 같은 개인 업무를 수행하는 데에만 사용됩니다.

  • 이메일 확인 및 전송
  • 파일 확인 및 작업
  • 일정 확인 및 관리
  • 문서 및 스프레드시트 작업
  • 연락처 조회

사용 대상

이 앱은 프로젝트 소유자 본인만 사용하는 개인용 애플리케이션이며, 불특정 다수의 사용자를 대상으로 하지 않습니다.

제3자 판매 및 광고 목적 사용

Google 사용자 데이터를 제3자에게 판매하지 않습니다.

Google 사용자 데이터를 광고 타기팅 목적으로 사용하지 않습니다.

불필요한 공개 제한

사용자가 요청한 업무 수행에 필요한 범위를 벗어나 Google 사용자 데이터를 외부에 공개하지 않습니다.

인증 정보

OAuth 인증 토큰은 Hermes Agent가 Google API에 접근하기 위한 용도로만 사용되며, 공개 웹페이지나 이 사이트에 노출되지 않습니다.

접근 권한 철회

사용자는 언제든지 Google 계정의 연결된 앱 및 보안 설정에서 Hermes Agent의 접근 권한을 철회할 수 있습니다.

이 페이지는 Google API Services User Data Policy에 따른 최소 고지 목적으로 작성되었으며, 서비스 구조 변경 시 업데이트될 수 있습니다.
