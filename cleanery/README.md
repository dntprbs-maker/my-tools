# 크리너리 입주청소

독립 제작한 입주청소 홈페이지를 my-tools의 `cleanery/`에서 관리한다.

## 실행 구분

- 마이툴즈 바로가기: `./cleanery/` → `public/`의 브라우저 미리보기. 하위 폴더에서도 이미지·메뉴·페이지 이동이 작동한다.
- 웹 미리보기는 화면·서비스·사례·FAQ를 둘러보는 용도이며 실제 고객 견적을 수집하거나 저장하지 않는다. 견적/조회 화면에 이 경계를 표시한다.
- 로컬 전체 기능: 이 폴더에서 Node.js24 이상으로 `npm start`, 기본 주소 `http://127.0.0.1:4317`. SQLite 견적 저장·비밀 조회키 조회 기능은 이 로컬 서버에서 실행된다.
- 기존 로컬 제작 폴더/서버는 보존한다. 앞으로 원본 코드는 이 저장소 폴더를 기준으로 관리한다.

## 확인

`npm test`로 입력·API·저장·재시작 검증, `npm run build`로 문법/자산/실행 번들 검사.

브랜드와 서비스 정보는 `public/config.mjs`, 사진은 `public/assets/`. 사진 라이선스는 `docs/사진-라이선스.md` 참조.

실제 상호 외 사업자정보·연락처·가격·실제사진·후기·보증·개인정보 정책은 별도 확정이 필요하다. 기존 운영앱·환경변수·운영 DB·비밀키는 복사하지 않았다. 테스트 데이터·실제 신청 DB·휴대폰 캡처·경쟁사 원문·Git 중첩 저장소도 포함하지 않는다.
