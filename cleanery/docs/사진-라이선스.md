현재 before/after는 동일 사진의 CSS 색상 효과 시연이며 실제 청소 결과가 아니다. 실제 작업 사진 등록 때 동일 구도 촬영·고객 게시 동의·주소와 얼굴 등 개인정보 비식별화를 확인해야 한다. 자산은 `public/assets/`, 서비스·사례 메타데이터는 `public/config.mjs`에서 교체한다. 실제 전후 쌍이 생기면 비교 컴포넌트의 두 img 소스를 각각 연결하고 시연 고지를 실제 정보로 수정한다.
